# RAG-Chat-WebApp

RAG Document Q&A WebApp — A Flutter web app where users upload files, which are chunked and stored as vector embeddings in PostgreSQL (pgvector). User questions are matched against these vectors via similarity search, and relevant chunks are passed to an LLM to generate grounded, context-aware answers.
